I tried out MCP with the basic weather example on their website today. It is pretty neat.
![](/images/essays/notion-1.png)
What I like about it is how easy it is to set up a server. Really all you need to do is:
1. Set up your API key
2. Make an API call
3. Place your output in a text-based format
4. ???
5. Profit!
At this point, things become so naturally easy to automate, at least from an API standpoint. You can think of building an agent that automatically grabs a bunch of data from APIs, reasons about them, then recommends them to you based on your stated preferences.
